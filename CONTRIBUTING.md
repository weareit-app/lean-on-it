# Contributing

## Setup

```sh
pnpm install
```

## Checks

```sh
pnpm check
```

runs typecheck, Biome, the Vitest tests, and the skills-sync and decision-record checks. CI runs the same checks on every pull request.

## Pull requests

Explain the problem, the change, and how you checked it. Record any changed decision in `docs/architecture/decisions.md`. Don't add tests for unrelated code.
